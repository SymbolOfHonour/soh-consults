# Site Manager foundation

- Added central validated Site Manager settings store.
- Added protected mobile-first `/admin/site-manager` editor.
- Added public-safe settings endpoint with private notes excluded.
- Added Site Manager to Operations Modules.
- Added `/admin/diagnostics` plain-English health checks.
- Added owner/developer recovery documentation and private admin metadata.

This foundation intentionally does not expose raw secrets, source code, authentication internals or database schema editing in owner-facing forms.
